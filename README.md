# SOCUD (System of Control Unstructured Data)

## 📌 Описание проекта
SOCUD — это система для контроля, обработки и интеллектуального анализа неструктурированных данных. Проект построен на микросервисной архитектуре, которая изолирует клиентский интерфейс, основную серверную логику и ресурсоемкую фоновую обработку данных с использованием ИИ.

## 📂 Структура репозитория
Репозиторий разделен на три основных логических модуля:

- `/socud-frontend` — Клиентская часть приложения (пользовательский интерфейс).
- `/socud-backend` — Основной API для маршрутизации клиентских запросов, управления бизнес-логикой и транзакциями БД.
- `/socud-ai-worker` — Изолированный сервис для асинхронной обработки неструктурированных файлов (распознавание текста, классификация, извлечение сущностей, векторизация).
- `docker-compose.yml` — Инфраструктурный манифест для оркестрации микросервисов и зависимостей (БД, очереди сообщений).

## 🛠 Стек технологий
*Проект реализован в единой экосистеме на базе TypeScript (93.5%).*

- **Frontend:** React.js / Next.js
- **Backend:**  Node.js (NestJS / Express / Fastify)
- **AI Worker:**  Node.js (LangChain.js, интеграция с LLM API, инструменты очередей типа BullMQ)
- **База данных:**  PostgreSQL (с поддержкой pgvector) + Object Storage (S3 / MinIO)
- **Брокер сообщений:  Redis / RabbitMQ
- **Контейнеризация:**  Docker, Docker Compose
